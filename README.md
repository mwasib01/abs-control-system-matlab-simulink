# Anti-lock Braking System (ABS) Modelling using MATLAB/Simulink


## Overview

This repository contains a MATLAB/Simulink based Anti-lock Braking System (ABS) model developed for vehicle braking dynamics analysis.

The project focuses on modelling wheel braking behaviour, analysing wheel slip, and evaluating ABS control performance during braking conditions.

The model demonstrates the interaction between vehicle dynamics, wheel rotation and braking control logic to maintain stable braking performance.


---

# Project Objectives

The main objectives are:

- Develop a vehicle ABS simulation model
- Analyse wheel and vehicle speed behaviour during braking
- Study slip ratio variation
- Evaluate braking control response
- Implement MATLAB/Simulink based automotive control modelling


---

# ABS Model

The Simulink model includes:

- Vehicle braking dynamics
- Wheel rotational dynamics
- Tire-road interaction
- Brake input modelling
- ABS control logic
- Parameter-based simulation setup


---

# System Analysis

The model evaluates:

## Vehicle Response

- Vehicle speed during braking
- Braking response behaviour


## Wheel Dynamics

- Wheel rotational speed
- Slip ratio behaviour
- Wheel locking prevention


## Control Performance

The ABS controller aims to:

- Prevent wheel lock-up
- Maintain tyre-road traction
- Improve vehicle stability during braking
